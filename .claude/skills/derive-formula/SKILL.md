# 公式推导 + 数值验证 + 可视化

## 流程

1. **陈述目标**：写出要推导的式子（论文公式号），列出前提假设（强可忽略性、Φ 可逆、平方损失、`ℓ/B_Φ ∈ G` 等）。
2. **逐步推导**：每一行只做一步变换，右侧标注依据（定义、Jensen、三角不等式、IPM 定义、贝叶斯公式、变量替换……）。
3. **标注哪些是论文原文、哪些是重建**：补充材料证明不在 PDF 中，重建的部分要明说。
4. **数值验证**：写一个小脚本（放 `src/verify_*.py`，或临时放 scratchpad），用合成数据检验结论。例如：
   - Theorem 1：构造已知 m₀, m₁ 的合成数据，数值计算 PEHE、ε_F、ε_CF 与 IPM，检验不等式；
   - 估计 MMD²（线性核/RBF）与 Wasserstein（1D 可用排序，高维用 `scipy` / POT）；
   - 改变处理组不平衡程度，观察 IPM 与 PEHE 的变化。
5. **可视化**：保存到 `figures/`，文件名 `NN_主题.png`，轴标注清晰。
6. **小结**：用一句话说明结论的直觉，再指出它在算法里对应的哪一项。

## 重点推导清单

- 强可忽略性 ⇒ τ(x) 可识别
- 分解 `ε_F = u·ε_F^{t=1} + (1-u)·ε_F^{t=0}`
- PEHE ≤ 2(ε_CF + ε_F − 2σ²)
- Lemma 1：`ε_CF − [(1-u)ε_F^{t=1} + uε_F^{t=0}] ≤ B_Φ · IPM`
- IPM 的特例：1-Lipschitz → Wasserstein-1；RKHS 单位球 → MMD
- 目标函数 (3) 中权重 `w_i` 的来源
