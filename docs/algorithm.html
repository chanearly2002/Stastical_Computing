目标函数（CFR / TARNet）论文 Sec 4 · Eq. (3)

把 Theorem 1 的上界改写成能在样本上计算的损失：加权预测损失 + 模型复杂度 + α 倍的两组表示的 IPM。Φ 被约束为 ‖Φ‖ = 1（归一化）。

minh, Φ, ‖Φ‖=1   (1/n) Σi=1n wi · L( h( Φ(xi), ti ), yi )  +  λ · ℜ(h) (3)
    + α · IPMG( { Φ(xi) }i : ti=0 , { Φ(xi) }i : ti=1 )
其中   wi = ti / (2u) + (1 − ti) / (2(1 − u)),   u = (1/n) Σi=1n ti,   ℜ 是模型复杂度项
原文（英文）
minh,Φ, ‖Φ‖=1 (1/n) Σi=1n wi · L(h(Φ(xi), ti), yi) + λ · ℜ(h) + α · IPMG({Φ(xi)}i:ti=0, {Φ(xi)}i:ti=1), with wi = ti/(2u) + (1−ti)/(2(1−u)), where u = (1/n) Σi=1n ti, and ℜ is a model complexity term. (3) — We refer to the model minimizing (3) with α > 0 as Counterfactual Regression (CFR) and the variant without balance regularization (α = 0) as Treatment-Agnostic Representation Network (TARNet).
符号含义
n训练样本数。
(xi, ti, yi)第 i 个事实样本：特征、实际处理、观测结果；i = 1…n。
h(Φ(xi), ti)假设对样本 i 的预测；用两个头实现，ti 决定走 h1 还是 h0。
Φ, ‖Φ‖=1表示网络；约束 ‖Φ‖ = 1 即对 Φ 归一化（论文：用投影，或固定尺度的 batch-normalization），因为 BΦ 被并入 α 后目标对 Φ 的尺度敏感。
L损失函数：连续结果用均方损失，二值结果用 log-loss（Sec 5）。
wi样本权重，补偿处理组与对照组人数不同；对应 Theorem 1 里的 u 与 (1−u)。
uu = (1/n)Σti，样本里处理组的比例，即 p(t=1) 的估计。
λ, ℜ(h)复杂度项的权重与复杂度项本身；实现中是对假设网络参数的小 ℓ2 权重衰减（Algorithm 1 第 9 行的 2λV）。
αIPM 项的权重（scaling parameter，α > 0 为 CFR，α = 0 为 TARNet）。Theorem 1 里的 BΦ 无法一般性计算，被当作超参数 α 的一部分。
IPMG(·,·)（经验）积分概率度量：Wasserstein 或 MMD。两个参数是 ti=0 与 ti=1 两组样本经 Φ 得到的表示。
GIPM 所用的函数族。
两个输出头论文 Sec 4

把 h(Φ, t) 拆成两个独立的头，各自只负责一种处理；每个样本只更新它观测到的处理对应的那个头。

h1(Φ) = h(Φ, 1),    h0(Φ) = h(Φ, 0)
原文（英文）
In Johansson et al. (2016), we parameterized h(Φ, t) with a single network, concatenating Φ and t as input. In this case, if Φ is high-dimensional, the influence of t on h might be lost during training. To combat this, we parameterize h1(Φ) = h(Φ, 1) and h0(Φ) = h(Φ, 0) as two separate “heads” of the joint network [...] Note that each sample is used to update only the head corresponding to the observed treatment.
符号含义
h1(Φ)估计处理（t = 1）下结果的头。
h0(Φ)估计对照（t = 0）下结果的头。
对比前作 Johansson et al. (2016) 把 Φ 与 t 拼接后输入单个网络 h(Φ, t)；Φ 维度高时 t 的影响可能在训练中丢失。
Algorithm 1：CFR（带 IPM 的反事实回归）论文 Sec 4

按 mini-batch 做随机梯度下降；预测损失与 IPM 项都在当前 mini-batch 上计算。

1: Input：事实样本 (x1, t1, y1), …, (xn, tn, yn)，缩放参数 α > 0，损失 L(·,·)，表示网络 ΦW（初始权重 W），结果网络 hV（初始权重 V），IPM 的函数族 G
2: u = (1/n) Σi=1n ti
3: wi = ti/(2u) + (1 − ti)/(2(1 − u)),   i = 1…n
4: while 未收敛 do
5:    抽 mini-batch { i1, i2, …, im } ⊂ {1, 2, …, n}
6:    g1 = ∇W IPMG( { ΦW(xij) }tij=0 , { ΦW(xik) }tik=1 )
7:    g2 = ∇V (1/m) Σj wij · L( hV( ΦW(xij), tij ), yij )
        g3 = ∇W (1/m) Σj wij · L( hV( ΦW(xij), tij ), yij )
8:    用标准神经网络方法（如 Adam）得到步长标量或矩阵 η
9:    [ W, V ] ← [ W − η( α g1 + g3 ),   V − η( g2 + 2λV ) ]
10:   检查收敛条件    11: end while
原文（英文）
Algorithm 1 CFR: Counterfactual regression with integral probability metrics. 1: Input: Factual sample (x1, t1, y1), ..., (xn, tn, yn), scaling parameter α > 0, loss function L(·,·), representation network ΦW with initial weights W, outcome network hV with initial weights V, function family G for IPM. 2: Compute u = (1/n) Σi=1n ti. 3: Compute wi = ti/(2u) + (1−ti)/(2(1−u)) for i = 1...n. 4: while not converged do 5: Sample mini-batch {i1, ..., im} ⊂ {1, 2, ..., n}. 6: Calculate the gradient of the IPM term: g1 = ∇W IPMG({ΦW(xij)}tij=0, {ΦW(xik)}tik=1). 7: Calculate the gradients of the empirical loss: g2, g3 [...] 8: Obtain step size scalar or matrix η with standard neural net methods e.g. Adam. 9: [W, V] ← [W − η(α g1 + g3), V − η(g2 + 2λV)]. 10: Check convergence criterion. 11: end while.
符号含义
mmini-batch 大小。
ij, ikmini-batch 中的样本下标（j、k 分别遍历对照组与处理组样本）。
W, V表示网络 ΦW 与结果网络 hV 的参数。
g1IPM 项对 W 的梯度（具体算法在补充材料，本 PDF 未给出）。
g2, g3加权预测损失对 V、对 W 的梯度。
η步长（标量或矩阵），如由 Adam 给出。
2λV对头参数做 ℓ2 权重衰减（即 λ‖V‖² 的梯度）；Φ 的参数 W 不带这一项。

三个设计问题

为什么 Φ 共享？

两个头学的是同一群人在两种处理下的结果，大部分结构（哪些特征重要）是共通的。共享表示层让两组样本一起训练 Φ，统计力量不被一分为二。

为什么要两个头？

把 t 当成一个输入拼到 Φ 后面，当 Φ 有几百维时，t 只是其中一个数，作用容易被淹没。两个头让"处理"决定走哪条路，作用不会丢。

为什么 IPM 接在 Φ(x) 上？

Theorem 1 里的距离是表示空间里两组分布的距离。所以惩罚必须加在 Φ(x) 上，让网络把两组"拉近"的同时，仍要预测准。

② 目标函数怎么来 Eq. 3

从 Theorem 1 的右边出发，改成能在样本上计算的形式，一共四步。

第 1 步

理论上界（Eq. 2）

PEHE ≤ 2 [ εFt=0 + εFt=1 + BΦ·IPM − 2σ² ]

右边的三个东西都和模型有关（噪声项 −2σ² 是常数，不影响优化）：两组各自的预测误差，以及两组在表示空间里的距离。

第 2 步

换成样本平均，得到加权损失

ε̂t=1 + ε̂t=0 = (1/n) Σᵢ 2wᵢ · ℓᵢ ,  wᵢ = tᵢ/(2u) + (1−tᵢ)/(2(1−u))

把处理组样本的损失除以 n₁、对照组的除以 n₀，再相加，就等于用权重 wᵢ 做平均。权重的作用是让两组各占一半，不让人数多的那组主导训练。下面有计算器。

第 3 步

BΦ 算不出来，并入 α

BΦ 依赖损失函数与表示的具体性质，一般无法计算。算法里把它当作超参数的一部分：α · IPM。

第 4 步

补上两件实际需要的东西

① 对假设网络参数加 ℓ₂ 正则 λ·R(h)，防过拟合；② 对 Φ 做归一化（投影，或固定尺度的 batch-norm）。第 ② 件事的理由见下面的演示。

minh,Φ  (1/n) Σᵢ wᵢ · L( h(Φ(xᵢ), tᵢ), yᵢ )  +  λ · R(h)  +  α · IPMG( {Φ(xᵢ)}tᵢ=0, {Φ(xᵢ)}tᵢ=1 )
项对应 Theorem 1作用
加权预测损失εFt=1 + εFt=0预测要准，保留与结果有关的信息
α · IPMBΦ · IPM两组表示要像，减少外推到"没见过的人群"的误差
λ · R(h)（普通正则）防止预测头过拟合

α = 0 时第二项消失，就是 TARNet；α > 0 是 CFR，IPM 取 Wasserstein 或线性核 MMD²，分别记作 CFR-Wass 与 CFR-MMD。

权重计算器 Eq. 3 的 wᵢ

演示：IPM 与预测损失怎么拉扯 自编演示，不是论文结果

下面把"表示 Φ"简化成一个方向：二维特征 (收入 x₁, 年龄 x₂) 投影到 θ 角的直线上，得到一维表示 r = x₁·cosθ + x₂·sinθ。数据是我编的：收入既影响谁用药，也影响结果；年龄只影响结果。两个头在这条直线上各拟合一条直线。所有数字都由页面里的代码现场计算。

这个演示不能说明什么：它只展示目标函数里两股力量的形状，没有展示 ITE 误差会变好或变差。这里的表示是一维线性的，丢掉收入还会引入偏差；论文里的收益来自有表达力的非线性网络和有限样本下的外推误差，这个小演示体现不出来。
为什么必须归一化 Φ：理论里缩小 Φ 会让 BΦ 变大，所以"缩小来作弊"不划算。算法把 BΦ 并入 α 之后，这个约束消失了，IPM 随 Φ 的尺度成比例缩小而预测损失不变，所以必须靠投影或固定尺度的 batch-norm 把尺度钉住。
