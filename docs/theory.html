Theorem 1论文 Sec 3.2 · Eq. (2)

条件：满足 Lemma 1 的条件，并且定义 ℓ 所用的损失 L 是平方损失。结论：个体效应的误差 εPEHE 先被"反事实 + 事实"损失之和控制，再被"两组各自的事实损失 + 两组分布的距离"控制。

εPEHE(h, Φ)  ≤  2 ( εCF(h, Φ) + εF(h, Φ) − 2σ2Y )  ≤ (2)
2 ( εt=0F(h, Φ) + εt=1F(h, Φ) + BΦ · IPMG( pt=1Φ , pt=0Φ ) − 2σ2Y )
原文（英文）
Theorem 1. Under the conditions of Lemma 1, and assuming the loss L used to define ℓh,Φ in Definitions 2 and 3 is the squared loss, we have:
εPEHE(h,Φ) ≤ 2( εCF(h,Φ) + εF(h,Φ) − 2σ²Y ) ≤ 2( εFt=0(h,Φ) + εFt=1(h,Φ) + BΦ IPMG(pΦt=1, pΦt=0) − 2σ²Y ),
where εF and εCF are defined w.r.t. the squared loss, and σ²Y is the variance of the outcomes Yt (see Definition A11 in Appendix for detailed definition).
符号含义
εPEHE(h, Φ)我们真正想小的量：个体效应估计的 PEHE 误差，对整个总体 p(x) 平均（Definition 6，Eq. 1）。
h, Φ假设 h 与表示 Φ；估计的效应是 f(x,t) = h(Φ(x), t) 给出的 f(x,1) − f(x,0)。
εCF(h, Φ)反事实损失：在"处理倾向被翻转"的分布 p(x, 1−t) 上的期望损失，无法直接估计（Definition 2）。
εF(h, Φ)事实损失：在真实分布 p(x, t) 上的期望损失，等于普通监督学习的泛化误差（Definition 2）。
εt=1F, εt=0F处理组、对照组各自的事实损失（Definition 3）；εF = u·εt=1F + (1−u)·εt=0F。
BΦ常数 BΦ > 0，使损失函数缩放后落入 IPM 所用函数族 G（Lemma 1 的条件）。
IPMG(·,·)积分概率度量，用函数族 G 衡量两个分布的距离。
pt=1Φ, pt=0Φ处理组、对照组的特征经 Φ 映射后，在表示空间 R 里的分布（Definition 1）。
σ2Y结果 Yt 的方差（噪声项）。因为 PEHE 按条件均值 mt(x) 定义，而 ℓ 里含有不可约的噪声，所以要减掉。具体定义（Definition A11）在补充材料，本 PDF 未给出。

一句话：个体效应的误差 ≤ 两个处理组各自的普通预测误差 + 两组在表示空间里的分布距离（再减去与模型无关的噪声项）。推导与数值检验见 ④。

① 问题与假设 Sec 1

医院里有旧药和新药，医生想知道：对这位具体的病人，新药比旧药好多少？这是个体处理效应（ITE）。论文用 Neyman–Rubin 潜在结果框架来写。

潜在结果与一致性论文 Sec 1

每个个体有两个潜在结果：用药和不用药各自的结果。但我们只能观测到实际接受的那一种，这条规则叫一致性假设。

x ∈ X,   t ∈ {0, 1}   →   潜在结果 Y0, Y1
观测规则：若 t = 0 则 y = Y0；若 t = 1 则 y = Y1   （即 y = Yt）
原文（英文）
For a unit with features x ∈ X, and an action t ∈ {0, 1}, there are two potential outcomes: Y0 and Y1. For each unit we only observe one of the potential outcomes, according to treatment assignment: if t = 0 we observe y = Y0, if t = 1, we observe y = Y1; this is known as the consistency assumption.
符号含义
x单位（个体）的特征，如化验指标、人口学信息，x ∈ X。
X特征空间（Sec 3.1 里设为 Rd 的有界子集）。
t处理（action / treatment / intervention），二元：t = 0 标准药，t = 1 新药。
Y0, Y1潜在结果：该个体若接受 t = 0 或 t = 1 会得到的结果，如血糖水平。
y实际观测到的结果，等于 Yt。另一个潜在结果永远看不到。
条件均值与个体处理效应 ITE论文 Sec 1

ITE 是"给定特征 x 时，新药相对旧药的期望效应"。它也叫条件平均处理效应（CATE）。目标是找到估计 τ̂，使某个损失（如均方误差）很小。

m1(x) = E[ Y1 | x ],    m0(x) = E[ Y0 | x ]
τ(x) := E[ Y1 − Y0 | x ] = m1(x) − m0(x)
目标：找 τ̂ 使 E[ ( τ̂ − τ )2 ] 很小
原文（英文）
We will denote m1(x) = E[Y1|x], m0(x) = E[Y0|x]. We are interested in learning the function τ(x) := E[Y1 − Y0|x] = m1(x) − m0(x). τ(x) is the expected treatment effect of t = 1 relative to t = 0 on a unit with characteristics x, or the Individual Treatment Effect (ITE). Our goal is to find an estimate τ̂ of τ such that some loss function, e.g. E[(τ̂ − τ)2], is small.
符号含义
m1(x), m0(x)条件均值函数：特征为 x 的人群，全部用新药 / 全部用旧药时的平均结果。
τ(x)个体处理效应 ITE（也叫 CATE）：t = 1 相对 t = 0 在特征为 x 的单位上的期望效应。
τ̂对 τ 的估计（待学习的函数）。
E[·]期望。
强可忽略性论文 Sec 1

两部分：没有隐藏混杂（给定 x 后，谁用药与潜在结果无关）和重叠（每种 x 的人两种药都有可能用到）。它是 τ(x) 可被识别的充分条件；论文说它无法从数据检验，只能靠领域知识判断。

( Y1, Y0 )  ⊥⊥  t  |  x
0 < p( t = 1 | x ) < 1    对所有 x
原文（英文）
We formalize this assumption by using the standard strong ignorability condition: (Y1, Y0) ⊥⊥ t | x, and 0 < p(t = 1|x) < 1 for all x. Strong ignorability is a sufficient condition for the ITE function τ(x) to be identifiable [...]: see proof in the supplement.
符号含义
⊥⊥统计独立。
( Y1, Y0 ) ⊥⊥ t | x给定 x，处理分配 t 与两个潜在结果独立：所有影响用药决定的因素都在 x 里（无隐藏混杂）。
p( t = 1 | x )倾向得分：特征为 x 的人被分到新药的概率。
0 < p < 1重叠：每个 x 都有机会得到两种处理。

它带来什么：在强可忽略性下，数据里可算的 E[y | x, t] 等于我们想要的 mt(x) = E[Yt | x]（这是识别的核心；论文把证明放在补充材料，这里只陈述结论，不是原文推导）。于是 ITE 变成"学两个回归函数再相减"。

平均处理效应 ATE论文 Sec 2

对 ITE 在总体上取平均，得到一个数。论文主要关心个体层面，但与 ATE 对比。

ATE = Ex∼p(x) [ τ(x) ]
符号含义
ATE平均处理效应。
p(x)特征 x 在总体中的分布。
Ex∼p(x)对 x 按 p(x) 取期望。

隐藏混杂的数字例子（自编）

设"积极性"没有被记录，一半人积极（500）、一半不积极（500）。药完全无效：积极者结果 0.8，不积极者 0.2，所以真实 τ = 0。但积极者 90% 去用药，不积极者 10% 去用药。

积极不积极合计平均结果 E[y | t]
用药组 t=145050500(450×0.8 + 50×0.2)/500 = 0.74
不用药组 t=050450500(50×0.8 + 450×0.2)/500 = 0.26

数据给出的"效应"是 0.74 − 0.26 = 0.48，真实效应是 0。原因：(Y1, Y0) ⊥⊥ t | x 被破坏，E[y | t=1] = E[Y1 | t=1] ≠ E[Y1]。这是偏差，数据再多也消不掉。若把"积极性"记入 x，则每一类内部两组结果相同，问题消失。

② 相关工作 Sec 2

这一节在回答：前人怎么估个体效应，缺什么，本文补什么。论文自己限定了范围：它假设因果结构简单且已知，即 (Y1, Y0) ⊥⊥ x | t 一类的设定、无隐藏混杂，所以不涉及因果发现。

方法族做法论文指出的问题 / 与本文的关系
协变量调整
（G-computation）		学 m1(x)、m0(x)，再相减，既可估 ITE 也可估 ATE以往多研究渐近一致性，缺有限样本泛化误差分析。本文指出一个被忽略的方差来源（两组分布不平衡），并提出新的正则：学习使两组 IPM 更小的表示，带来新的偏差-方差权衡
加权方法
（IPW 等）		按倾向得分重新加权，使两组更可比；也用于估计条件效应高维时方差难控制；双重稳健方法把加权与协变量调整结合，减小模型偏差
机器学习做个体效应树方法（Wager & Athey；Athey & Imbens），有随机实验数据时找异质性，神经网络（含 deep IV）本文关注泛化误差而不是渐近一致性，且只用观测数据，不依赖随机实验或工具变量
域适应训练分布与测试分布不同时的泛化界（Ben-David 等，A-distance、discrepancy 距离），DANN（Ganin 等）本文的误差界与之相似，所用 IPM 与这些距离相关；算法与 DANN 类似
前作 BNN
（Johansson et al. 2016）		学平衡表示，其上拟合线性岭回归，两步优化前作只有"相对误差界"（比较反转处理分配与事实分配下的岭回归），不能说明表示的绝对好坏；本文给出绝对误差界，支持非线性假设和 Wasserstein/MMD，并做了更充分的实验

沿用上面的观测数据：p(t=1 | 富) = 300/400 = 0.75，p(t=1 | 穷) = 100/600 = 1/6。给处理组每个人的权重取 1/p(t=1 | x)：富人 ≈ 1.33，穷人 = 6。加权后处理组：富 300×1.33 = 400，穷 100×6 = 600，恢复总体构成。代价：100 个穷人被放大 6 倍，p(t=1 | x) 越接近 0，权重越大，方差越难控制。若某类人的 p(t=1|x) 变成 1/100，权重就是 100。

③ 符号与定义 Sec 3.1

这一节给 Theorem 1 备好"词汇表"。每张卡片是论文的一条定义，下面列出所有变量。

问题设定论文 Sec 3.1

特征空间有界、结果是实数、处理是二元变量，存在一个满足强可忽略性的联合分布。处理组与对照组的分布就是按处理条件化的特征分布。

X ⊂ Rd 有界,   Y ⊂ R,   t ∈ {0, 1}
联合分布 p( x, t, Y0, Y1 )，满足强可忽略性：( Y1, Y0 ) ⊥⊥ t | x,   0 < p( t=1 | x ) < 1
pt=1(x) := p( x | t = 1 ),    pt=0(x) := p( x | t = 0 )
原文（英文）
The space of covariates is a bounded subset X ⊂ Rd. The outcome space is Y ⊂ R. Treatment t is a binary variable. We assume there exists a joint distribution p(x, t, Y0, Y1), such that (Y1, Y0) ⊥⊥ t|x and 0 < p(t = 1|x) < 1 for all x ∈ X (strong ignorability). The treated and control distributions are the distribution of the features x conditioned on treatment: pt=1(x) := p(x|t = 1), and pt=0(x) := p(x|t = 0), respectively.
符号含义
d特征维度。
X协变量（特征）空间，Rd 的有界子集。
Y结果空间，R 的子集。
pt=1(x)处理组分布：只看被分到 t=1 的单位，其特征 x 的分布。
pt=0(x)对照组分布：只看被分到 t=0 的单位，其特征 x 的分布。
Assumption 1 与 Definition 1：表示函数 Φ论文 Sec 3.1

Φ 把特征换成新的"坐标"，要求一一映射、可微，也就是不丢信息，可以还原。这样才能用变量替换公式把两组分布搬到表示空间里。

Φ : X → R  （R = Φ 的像，表示空间）
Assumption 1：Φ 二阶可微且一一映射；存在逆 Ψ : R → X，Ψ( Φ(x) ) = x 对所有 x ∈ X
Definition 1：pt=1Φ(r) := pΦ( r | t = 1 ),    pt=0Φ(r) := pΦ( r | t = 0 )
原文（英文）
Assumption 1. The representation Φ is a twice-differentiable, one-to-one function. Without loss of generality we will assume that R is the image of X under Φ. We then have Ψ : R → X as the inverse of Φ, such that Ψ(Φ(x)) = x for all x ∈ X. — Definition 1. Define pΦt=1(r) := pΦ(r|t = 1), pΦt=0(r) := pΦ(r|t = 0), to be the treated and control distributions induced over R.
符号含义
Φ表示函数（representation function）。
R表示空间；不失一般性取为 X 在 Φ 下的像。
ΨΦ 的逆映射。
pΦΦ 把 X 上的分布"推前"到 R 上得到的分布。
pt=1Φ(r), pt=0Φ(r)处理组、对照组在表示空间里的分布。一一映射时，可用变量替换公式（涉及 Ψ 的雅可比行列式）由 pt=1、pt=0 得到。
Definition 2：损失 ℓ，事实损失与反事实损失论文 Sec 3.1

先定义单个"(特征, 处理)"的期望损失 ℓ，再把它分别对"事实分布 p(x,t)"与"处理被翻转的分布 p(x,1−t)"积分。反事实世界就是人还是那群人（p(x) 不变），但医生的开药倾向反过来。

h : R × {0, 1} → Y,    L : Y × Y → R+
ℓh,Φ(x, t) = ∫Y L( Yt, h(Φ(x), t) ) · p( Yt | x ) dYt
εF(h, Φ) = ∫X×{0,1} ℓh,Φ(x, t) · p(x, t) dx dt
εCF(h, Φ) = ∫X×{0,1} ℓh,Φ(x, t) · p(x, 1−t) dx dt
原文（英文）
Definition 2. The expected loss for the unit and treatment pair (x, t) is: ℓh,Φ(x, t) = ∫Y L(Yt, h(Φ(x), t)) p(Yt|x) dYt. The expected factual and counterfactual losses of h and Φ are: εF(h, Φ) = ∫X×{0,1} ℓh,Φ(x, t) p(x, t) dx dt, εCF(h, Φ) = ∫X×{0,1} ℓh,Φ(x, t) p(x, 1−t) dx dt.
符号含义
h假设：在表示空间上预测结果，h(Φ(x), t)。
L损失函数，取值非负，如平方损失。
ℓh,Φ(x, t)对"特征 x、处理 t"这一对，模型预测的期望损失，对潜在结果 Yt 的随机性取平均。
p( Yt | x )给定 x，潜在结果 Yt 的条件分布。
εF(h, Φ)事实损失（Factual）：在真实分布 p(x, t) 上的平均，可从数据估计。
εCF(h, Φ)反事实损失（Counterfactual）：在 p(x, 1−t) 上的平均。只有事实样本，所以不能直接估计。
p(x, 1−t)把处理标签翻转后的联合分布：等于 p(x)·p(1−t | x)。
Definition 3：两组各自的事实损失论文 Sec 3.1

把事实损失按处理组、对照组拆开，各自在组内分布上取平均。拆开后，总的事实损失是两者按人数比例加权。

εt=1F(h, Φ) = ∫X ℓh,Φ(x, 1) · pt=1(x) dx
εt=0F(h, Φ) = ∫X ℓh,Φ(x, 0) · pt=0(x) dx
令 u := p(t = 1)：  εF(h, Φ) = u · εt=1F(h, Φ) + (1 − u) · εt=0F(h, Φ)
原文（英文）
Definition 3. The expected factual treated and control losses are: εFt=1(h, Φ) = ∫X ℓh,Φ(x, 1) pt=1(x) dx, εFt=0(h, Φ) = ∫X ℓh,Φ(x, 0) pt=0(x) dx. For u := p(t = 1), it is immediate to show that εF(h, Φ) = u εFt=1(h, Φ) + (1 − u) εFt=0(h, Φ).
符号含义
εt=1F(h, Φ)处理组上的平均损失（用 h1 预测处理组自己）。
εt=0F(h, Φ)对照组上的平均损失。
uu := p(t=1)，总体里被处理的比例。由强可忽略性，0 < u < 1。
Definitions 4-6：ITE、估计的 ITE 与 PEHE论文 Sec 3.1 · Eq. (1)

PEHE（Precision in Estimation of Heterogeneous Effect，Hill 2011）是我们真正想小的量：估计的个体效应与真实个体效应之差的平方，在整个总体 p(x) 上平均。

Def 4：τ(x) := E[ Y1 − Y0 | x ]
假设 f : X × {0, 1} → Y，例如 f(x, t) = h( Φ(x), t )
Def 5：τ̂f(x) = f(x, 1) − f(x, 0)
Def 6：εPEHE(f) = ∫X ( τ̂f(x) − τ(x) )2 · p(x) dx  (1)
当 f(x, t) = h( Φ(x), t ) 时，记 εPEHE(h, Φ) := εPEHE(f)
原文（英文）
Definition 6. The expected Precision in Estimation of Heterogeneous Effect (PEHE, Hill (2011)) loss of f is: εPEHE(f) = ∫X (τ̂f(x) − τ(x))2 p(x) dx, (1). When f(x, t) = h(Φ(x), t), we will also use the notation εPEHE(h, Φ) = εPEHE(f).
符号含义
τ(x)真实 ITE（Def 4，与 Sec 1 相同）。
f定义在 X × {0,1} 上的假设；f(x,t) = h(Φ(x),t) 是它的一个例子。
τ̂f(x)假设 f 对单位 x 给出的处理效应估计 = f(x,1) − f(x,0)。
εPEHE(f)f 的 PEHE 损失：ITE 估计误差的平方，对 p(x) 积分。
p(x)总体的特征分布。
积分概率度量 IPM论文 Sec 3.1

挑一族函数 G，找出最能区分 p 与 q 的那个函数 g，看它在两个分布下的平均值差多大。差得越多，两个分布越不同。

IPMG(p, q) := supg ∈ G | ∫S g(s) ( p(s) − q(s) ) ds |
原文（英文）
For two probability density functions p, q defined over S ⊆ Rd, and for a function family G of functions g : S → R, we have that IPMG(p, q) := supg∈G |∫S g(s)(p(s) − q(s)) ds|. Integral probability metrics are always symmetric and obey the triangle inequality, and trivially satisfy IPMG(p, p) = 0. For rich enough function families G, we also have that IPMG(p, q) = 0 ⟹ p = q, and then IPMG is a true metric.
符号含义
p, q定义在 S ⊆ Rd 上的两个概率密度。
G函数 g : S → R 的一个函数族。
sup上确界：在 G 里取使绝对值最大的那个 g。
性质总是对称、满足三角不等式，且 IPMG(p, p) = 0。当 G 足够丰富时，IPMG(p, q) = 0 ⟹ p = q，它就是真正的距离。
G 的例子有界连续函数族；1-Lipschitz 函数族（对应 Wasserstein 距离，记 Wass(p, q)）；通用 RKHS 的单位球（对应 MMD，记 MMD(p, q)）。三者都使 IPM 成为真度量。

④ Lemma 1 与 Theorem 1 Sec 3.2

目标：PEHE 依赖真实 ITE，算不出来；εF 能估计，εCF 不能。定理要用"能估计的量"给 PEHE 找一个上界。先看两个陈述，再看推导，最后用数字检验。

εCF(h, Φ)  ≤

原文（英文）
Lemma 1. Let Φ : X → R be a one-to-one representation function, with inverse Ψ. Let h : R × {0, 1} → Y be an hypothesis. Let G be a family of functions g : R → Y. Assume there exists a constant BΦ > 0, such that for fixed t ∈ {0, 1}, the per-unit expected loss functions ℓh,Φ(Ψ(r), t) (Definition 2) obey (1/BΦ) · ℓh,Φ(Ψ(r), t) ∈ G. We have: εCF(h, Φ) ≤ (1 − u) εFt=1(h, Φ) + u εFt=0(h, Φ) + BΦ · IPMG(pΦt=1, pΦt=0), where εCF, εFt=0 and εFt=1 are as in Definitions 2 and 3.
符号含义
Φ : X → R一一映射的表示函数，逆为 Ψ（Assumption 1）。
h : R × {0,1} → Y假设。
G函数族，其中的函数 g : R → Y（论文原文如此写）。
BΦ > 0存在这样的常数：对固定的 t ∈ {0, 1}，逐单位期望损失 ℓh,Φ(Ψ(r), t)（Definition 2）满足 (1/BΦ) · ℓh,Φ(Ψ(r), t) ∈ G。
u := p(t = 1)总体处理比例，由强可忽略性 0 < u < 1。
εCF, εt=1F, εt=0FDefinitions 2 与 3 中的量。
IPMG(pt=1Φ, pt=0Φ)表示空间里两组分布的 IPM 距离。

原文（英文）
Theorem 1. Under the conditions of Lemma 1, and assuming the loss L used to define ℓh,Φ in Definitions 2 and 3 is the squared loss, we have:
εPEHE(h,Φ) ≤ 2( εCF(h,Φ) + εF(h,Φ) − 2σ²Y ) ≤ 2( εFt=0(h,Φ) + εFt=1(h,Φ) + BΦ IPMG(pΦt=1, pΦt=0) − 2σ²Y ),
where εF and εCF are defined w.r.t. the squared loss, and σ²Y is the variance of the outcomes Yt (see Definition A11 in Appendix for detailed definition).
符号含义
εPEHE(h, Φ)我们真正想小的量：个体效应估计的 PEHE 误差，对整个总体 p(x) 平均（Definition 6，Eq. 1）。
h, Φ假设 h 与表示 Φ；估计的效应是 f(x,t) = h(Φ(x), t) 给出的 f(x,1) − f(x,0)。
εCF(h, Φ)反事实损失：在"处理倾向被翻转"的分布 p(x, 1−t) 上的期望损失，无法直接估计（Definition 2）。
εF(h, Φ)事实损失：在真实分布 p(x, t) 上的期望损失，等于普通监督学习的泛化误差（Definition 2）。
εt=1F, εt=0F处理组、对照组各自的事实损失（Definition 3）；εF = u·εt=1F + (1−u)·εt=0F。
BΦ常数 BΦ > 0，使损失函数缩放后落入 IPM 所用函数族 G（Lemma 1 的条件）。
IPMG(·,·)积分概率度量，用函数族 G 衡量两个分布的距离。
pt=1Φ, pt=0Φ处理组、对照组的特征经 Φ 映射后，在表示空间 R 里的分布（Definition 1）。
σ2Y结果 Yt 的方差（噪声项）。因为 PEHE 按条件均值 mt(x) 定义，而 ℓ 里含有不可约的噪声，所以要减掉。具体定义（Definition A11）在补充材料，本 PDF 未给出。

BΦ 是什么、怎么得到 论文 Sec 3.2 后的说明

  • G 越小，界越紧；但太小会得到无法计算的界。例如最小的选择 G = { ℓh,Φ(x,0), ℓh,Φ(x,1) } 需要在 pt=0Φ 上算 Y1 的期望、在 pt=1Φ 上算 Y0 的期望，而这些根本观测不到。
  • 论文用两个函数族：1-Lipschitz 函数族，IPM 就是 Wasserstein 距离 Wass(p, q)；范数不超过 1 的 RKHS 函数，IPM 就是 MMD(p, q)。两者都能从有限样本一致地估计。
  • 要显式算出 BΦ，需要额外假设。Wasserstein 情形：损失 L、p(Yt|x) 与 h 的 Lipschitz 常数、Φ 的雅可比矩阵的条件数。MMD 情形：h、Φ 的 RKHS 可表示性与范数，以及 Yt|x 的标准差。完整细节在补充材料的 Theorem 2 与 3，本 PDF 未给出。
  • 把 Φ 缩小会让 BΦ 变大，所以定理里不会出现"把 Φ 缩得任意小来让 IPM 变 0"这类平凡解。（这条保护在算法里消失，因为 BΦ 被并入 α，所以算法要归一化 Φ，见 算法图解。）
  • 对有限样本：εt=0F 与 εt=1F 还能进一步用各自的经验损失加上模型复杂度项来上界（标准的学习理论论证）；IPM 也能从有限样本一致估计。
  • 负的方差项 σ2Y：来自这样一个事实：PEHE 是按条件均值函数 mt(x) 定义的，而不是去拟合随机变量 Yt。
Lemma 1 的推导（重建：补充材料中的证明不在本 PDF，以下是按正文思路与定义写出的推导，已数值检验）
  1. 按 t 拆开（Def 2，对 t 求和）：εCF = ∫ ℓh,Φ(x,1) p(x, t=0) dx + ∫ ℓh,Φ(x,0) p(x, t=1) dx。反事实世界里，评估"用新药"的损失用的是没用新药的人。
  2. 用边缘概率改写：p(x, t=0) = (1−u) pt=0(x)，p(x, t=1) = u pt=1(x)，所以 εCF = (1−u)∫ ℓh,Φ(x,1) pt=0 dx + u ∫ ℓh,Φ(x,0) pt=1 dx。
  3. 减去 (1−u)εt=1F + uεt=0F（Def 3），差为 (1−u)∫ ℓh,Φ(x,1)[pt=0 − pt=1]dx + u∫ ℓh,Φ(x,0)[pt=1 − pt=0]dx。差只剩"同一个损失函数在两组分布下的平均之差"。
  4. Φ 一一映射 ⟹ 变量替换：∫ ℓh,Φ(x,t) p(x) dx = ∫ ℓh,Φ(Ψ(r), t) pΦ(r) dr，积分搬到表示空间。这一步用到 Assumption 1；没有 Ψ，ℓ(Ψ(r),t) 就没有意义。
  5. 因为 ℓh,Φ(Ψ(r),t)/BΦ ∈ G，由 IPM 定义，∫ ℓh,Φ(Ψ(r),t)(p − q) dr = BΦ ∫ (ℓh,Φ/BΦ)(p − q) ≤ BΦ · IPMG(p, q)。
  6. 两项的系数 (1−u) + u = 1，得到 Lemma 1。
Theorem 1 的推导（重建，同上）
  1. 把 ITE 误差写成 τ̂f − τ = a − b，其中 a = f(x,1) − m1(x)，b = f(x,0) − m0(x)。
  2. (a − b)2 ≤ 2a2 + 2b2。
  3. 平方损失的分解：ℓh,Φ(x,t) = E[(Yt − f(x,t))2 | x]。f(x,t) 在固定 x 时是常数，记 mt = E[Yt|x]。把 (Yt − f) 写成 (Yt − mt) + (mt − f) 再展开平方：(Yt − mt)2 + 2(Yt − mt)(mt − f) + (mt − f)2。取条件期望，交叉项因 E[Yt − mt | x] = 0 而消失，所以
    ℓh,Φ(x,t) = ( f(x,t) − mt(x) )2 + Var( Yt | x )（精确等式）。
  4. 于是 a2、b2 分别等于 ℓh,Φ(x,1) − Var(Y1|x)、ℓh,Φ(x,0) − Var(Y0|x)，代入第 2 步并对 p(x) 积分：εPEHE ≤ 2[ ∫(ℓh,Φ(x,1)+ℓh,Φ(x,0)) p(x) dx − ∫(Var(Y1|x)+Var(Y0|x)) p(x) dx ]。
  5. 关键一步：对每个 t，p(x,t) + p(x,1−t) 对 t 求和后等于 p(x,0) + p(x,1) = p(x)，所以 ∫(ℓh,Φ(x,1)+ℓh,Φ(x,0)) p(x) dx = εF + εCF。PEHE 要求模型对所有 x 同时预测两种处理，正好是事实世界与反事实世界的合成。
  6. 得第一个不等号：εPEHE ≤ 2( εF + εCF − 噪声项 )。论文把噪声项写作 2σ2Y；Definition A11 不在本 PDF，我的重建里它对应 ∫(Var(Y1|x)+Var(Y0|x))p(x)dx，是否与论文逐字等同未核实，但作用相同：与模型无关的常数。
  7. 代入 Lemma 1，并用 εF = uεt=1F + (1−u)εt=0F：εF + (1−u)εt=1F + uεt=0F = εt=1F + εt=0F。得第二个不等号，即 Eq. (2)。

数字检验：把 Lemma 1 与 Theorem 1 算一遍 自编：两类人的玩具例子，无噪声

特征只有两种：富人 R（占 40%）、穷人 P（占 60%），两点之间距离设为 1，所以 1-Lipschitz 函数族下的 IPM 就是 Wasserstein，等于 |p(R|t=1) − p(R|t=0)|。结果无噪声，所以 σ2Y = 0。真实结果：m0(R)=2，m1(R)=5，m0(P)=1，m1(P)=2。模型 f 在 (R,0)、(R,1)、(P,0) 上都是对的，只有 (P,1) 处的预测可调。拖动滑块，看每个量怎么变，以及不等式是否始终成立。

每一项在说什么

预测误差项 εt=0F + εt=1F

普通监督学习的泛化误差，两组各算各的。模型在两组各自的人群上预测得准，这一项就小。

距离项 BΦ · IPMG

两组人群在表示空间里差多远。差得越远，把"在已见区域学到的"外推到"没见过的区域"就越不可靠。随机试验中 t ⊥⊥ x，两组分布相同，这项为 0。

噪声项 −2σ2Y

与模型无关的常数。它出现是因为 PEHE 用条件均值 mt(x) 定义，而 ℓ 里含有不可约的结果噪声。

这两条定理在算法里的对应：εt=0F + εt=1F → 加权预测损失；BΦ · IPMG → α · IPM；Φ 一一映射 → 算法里改用对 Φ 归一化来防止作弊。详见 算法图解 与 实验图解。
