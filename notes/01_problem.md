# 01 问题设定与第 1 节自测题讲解

## p(x|t=1) 与 p(x|t=0)

- p(x|t=1)：只看用了新药的人，他们的特征 x 如何分布。p(x|t=0) 同理，指旧药组。
- 公式：p(x|t) = p(t|x) p(x) / p(t)。随机化时 p(t|x) 与 x 无关，所以 p(x|t) 不依赖 t。

### 数值例子（1000 人，富人 400，穷人 600）

观测数据：

| | 富人 | 穷人 | 富人占比 |
|---|---|---|---|
| t=1（400 人）| 300 | 100 | 75% |
| t=0（600 人）| 100 | 500 | 17% |

RCT（40% 随机分到新药）：

| | 富人 | 穷人 | 富人占比 |
|---|---|---|---|
| t=1（400 人）| 160 | 240 | 40% |
| t=0（600 人）| 240 | 360 | 40% |

## Q1 随机化与 IPM

随机化 → t ⊥ x → p(x|t=1) = p(x|t=0) → IPM = 0 → Theorem 1 退化为两个普通回归问题。

## Q2 隐藏混杂

- 想知道的：m_t(x) = E[Y_t | x]（因果量）。
- 数据能算的：E[y | x, t]。
- 强可忽略性保证两者相等；破坏后差值是混杂偏差，数据量增加也消不掉。

玩具例子（自编，非论文内容）：积极性未记录，药物无效（Y₁ = Y₀，积极者 0.8，不积极者 0.2），积极者 90% 用药，不积极者 10% 用药。
- 用药组平均结果 0.74，不用药组 0.26，表观效应 0.48，真实效应 0。

## Q3 ITE 与 ATE

- ITE：函数 τ(x)；ATE = E[τ(x)]，一个数。
- 年轻人 τ=+10，老年人 τ=−10，各半：ATE=0。预测全 0 的模型与预测符号全反的模型，ATE 都正确，ITE 都错。
- ATE 误差 = |平均(τ̂−τ)|，可抵消；PEHE = 平均(τ̂−τ)²，不抵消。
- 论文表 1（Jobs，样本内）：LR1 的 ATT 误差 0.01、policy risk 0.22；CFR-Wass 的 ATT 误差 0.04、policy risk 0.17。
