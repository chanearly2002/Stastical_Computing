# 02 相关工作（论文 Sec 2）

## 主旨
说明本文在已有方法中的位置：协变量调整、加权、ML 方法、域适应、作者 2016 年 BNN 论文，各自缺什么，本文补什么。

## 方法对照

| 方法族 | 做法 | 论文指出的问题 / 与本文关系 |
|---|---|---|
| 协变量调整（G-computation）| 学 m₁(x), m₀(x) 再相减 | 以往多研究渐近一致性，缺有限样本泛化误差分析。本文指出其被忽略的方差来源（两组分布不平衡），并提出新的正则：减小表示空间中两组的 IPM，形成新的偏差-方差权衡 |
| 加权（IPW 等）| 按 1/p(t|x) 重加权使两组可比 | 高维时方差难控制；双重稳健方法结合加权与调整以减小模型偏差 |
| ML 做个体效应 | 树方法（Wager & Athey, Athey & Imbens）、有随机实验数据时找异质性、神经网络（Hartford 等 deep IV）| 本文关注泛化误差而非渐近一致性，且只用观测数据，无随机成分或工具变量 |
| 域适应 | 训练分布与测试分布不同时的泛化界（Ben-David 等，A-distance / discrepancy），DANN（Ganin 等）| 本文的界与之相似，所用 IPM 与这些距离相关，算法与 DANN 类似 |
| Johansson et al. 2016（BNN）| 学平衡表示 + 线性岭回归，两步优化 | 只有"相对误差界"，无法说明表示的绝对好坏；本文给出绝对误差界，支持非线性假设和 Wass/MMD，并做了更充分的实验（含真实数据与样本外）|

## IPW 数值例子（取 Sec 1 的富人/穷人观测表）
p(t=1|富) = 300/400 = 0.75，p(t=1|穷) = 100/600 = 1/6。
处理组权重 = 1/p(t=1|x)：富人 1.33，穷人 6。
加权后处理组：富 300×1.33 = 400，穷 100×6 = 600，恢复总体构成。
代价：100 个穷人被放大 6 倍，p(t=1|x) 越接近 0 权重越大，方差越大。
