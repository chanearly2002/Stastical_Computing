# 04 Lemma 1 与 Theorem 1（论文 Sec 3.2）

> 完整证明在论文补充材料中，不在本 PDF 内。以下为根据正文思路的**重建推导**，并已数值验证（src/verify_thm1.py）。

记 ℓ(x,t) = ℓ_{h,Φ}(x,t)，u = p(t=1)。p(x,1)=u·p_{t=1}(x)，p(x,0)=(1−u)·p_{t=0}(x)。

## Lemma 1：ε_CF ≤ (1−u)ε_F^{t=1} + u ε_F^{t=0} + B_Φ·IPM_G(p_Φ^{t=1}, p_Φ^{t=0})
1. ε_CF = ∫ℓ(x,1)p(x,0)dx + ∫ℓ(x,0)p(x,1)dx（Def 2，对 t 求和）
2. = (1−u)∫ℓ(x,1)p_{t=0}dx + u∫ℓ(x,0)p_{t=1}dx
3. 减去 (1−u)ε_F^{t=1} + uε_F^{t=0}（Def 3），差为
 (1−u)∫ℓ(x,1)[p_{t=0}−p_{t=1}]dx + u∫ℓ(x,0)[p_{t=1}−p_{t=0}]dx
4. Φ 一一映射 → 变量替换 ∫ℓ(x,t)p(x)dx = ∫ℓ(Ψ(r),t)p_Φ(r)dr，积分搬到表示空间
5. 假设 ℓ(Ψ(r),t)/B_Φ ∈ G，由 IPM 定义，每个积分 ≤ B_Φ·IPM_G
6. 权重 (1−u)+u = 1，得结论。

## Theorem 1（平方损失）：PEHE ≤ 2(ε_CF + ε_F − 2σ²) ≤ 2(ε_F^{t=0} + ε_F^{t=1} + B_Φ·IPM − 2σ²)
1. τ̂−τ = a − b，a = f(x,1)−m₁(x)，b = f(x,0)−m₀(x)
2. (a−b)² ≤ 2a² + 2b²
3. 平方损失的偏差-方差分解：ℓ(x,t) = (f(x,t)−m_t(x))² + Var(Y_t|x)
4. 故 PEHE ≤ 2[∫(ℓ(x,1)+ℓ(x,0))p(x)dx − ∫(Var(Y₁|x)+Var(Y₀|x))p(x)dx]
5. p(x,t)+p(x,1−t) 对 t 求和 = p(x)，所以 ∫(ℓ(x,1)+ℓ(x,0))p(x)dx = ε_F + ε_CF
6. 得第一个不等号。噪声项在论文里写作 2σ_Y²（定义 A11 在补充材料，本 PDF 未给出）；重建中对应 ∫(Var(Y₁|x)+Var(Y₀|x))p(x)dx，是否与论文逐字等同未核实。它与模型无关，来自 PEHE 用条件均值 m_t 定义。
7. 代入 Lemma 1，并用 ε_F = uε^{t=1}+(1−u)ε^{t=0}：ε_F + (1−u)ε^{t=1} + uε^{t=0} = ε^{t=1} + ε^{t=0}，得第二个不等号。

## 数值验证
- 玩具例（Sec 3.1）：ε_CF = 2.0 ≤ 0.6 + 4×0.5833 = 2.933；PEHE 2.4 ≤ 2(ε_F+ε_CF) = 4.8 ≤ 2(ε^1+ε^0+B·W) = 6.667。
- 100000 个随机离散问题，两种 IPM（|g|≤1 与 1-Lipschitz/Wasserstein）：全部不等式无违反；PEHE/最终界的最大比值 0.864 / 0.900。
- 图 figures/03_thm1_chain.png：(a) 玩具链；(b) PEHE 与界的散点，界通常较松；(c) 误差集中在稀疏格子时，不平衡越强，ε_CF/ε_F 与 IPM 越大（s=0 时比值 1.0，s=5 时约 287，这是自设的模拟，不是论文结果）。

## 要点
- 随机化时 IPM=0，但 ε_CF 与 ε_F 一般仍差在权重 (1−u,u) 与 (u,1−u)，仅 u=1/2 时相等。
- B_Φ 无法一般性计算，实践中并入 α。
- 界通常很松，它指示方向，不是紧的数值保证。
