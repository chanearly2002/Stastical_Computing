# 05 算法：CFR / TARNet（论文 Sec 4）

## 结构（Fig 1）
- 共享表示网络 Φ，两个输出头 h₁、h₀；每个样本只更新其实际处理对应的头。
- 原因：前作把 t 拼进单个网络输入，Φ 维度高时 t 的影响可能被淹没。

## 目标函数（Eq.3）
min (1/n)Σ wᵢ L(h(Φ(xᵢ),tᵢ), yᵢ) + λR(h) + α·IPM_G({Φ(xᵢ)}_{t=0}, {Φ(xᵢ)}_{t=1})
wᵢ = tᵢ/(2u) + (1−tᵢ)/(2(1−u))，u = (1/n)Σtᵢ。

- 权重来自 Theorem 1：ε̂^{t=1}+ε̂^{t=0} 各自是组内平均，Σᵢℓᵢ[tᵢ/n₁ + (1−tᵢ)/n₀] = (1/n)Σᵢ 2wᵢℓᵢ，所以 (1/n)Σ wᵢℓᵢ = ½(ε̂^{t=1}+ε̂^{t=0})，常数 2 并入 α 等超参数。已数值核对：Σwᵢ = n，两组各占总权重 n/2。
- 这与 IPW 的 1/p(t|x) 不同：只补偿两组样本量，不做个体级重加权。
- B_Φ 无法计算，并入 α。因此目标对 Φ 的尺度敏感，需归一化 Φ（投影，或固定尺度的 batch-norm），否则可缩小 Φ 来作弊。
- α>0：CFR（CFR-Wass / CFR-MMD）；α=0：TARNet。
- R(h)：对假设网络参数的 ℓ2 权重衰减。

## Algorithm 1（mini-batch）
1. u = mean(t)；wᵢ 按上式。
2. 循环：抽 mini-batch；
 g1 = ∇_W IPM({Φ_W(x)}_{t=0}, {Φ_W(x)}_{t=1})（batch 内计算）
 g2 = ∇_V (1/m)Σ w·L(h_V(Φ_W(x),t), y)
 g3 = ∇_W (1/m)Σ w·L(...)
3. 更新 [W,V] ← [W − η(αg1 + g3), V − η(g2 + 2λV)]，η 用 Adam 等。

## 实现设置（Sec 5，论文给出的）
- Φ：3 层全连接 ELU；h：3 层。层宽：Jobs 全部 200；IHDP 表示 200、假设 100。
- Adam；假设参数小的 ℓ2 衰减；连续结果用均方损失，二值结果用 log-loss（理论不直接覆盖 log-loss）。
- IPM：Wasserstein（CFR-Wass）、线性核 MMD²（CFR-MMD）。

## 本人观察（论文未展开）
